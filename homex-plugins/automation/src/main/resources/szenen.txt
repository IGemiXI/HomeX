#  Szenen – mehrere Befehle auf einen Klick (Dashboard) oder per
#  Konsole:  szene Gute Nacht
#
#  szene <Name> | <Symbol>
#    <Ziel> <Schlüssel> <Wert>
#    ...
#
#  Ziel:   eine Geräte-ID (z. B. licht-kueche)
#          raum:<Raum>            alle Geräte in einem Raum
#          typ:<Typ>              licht, steckdose, rollladen, klima
#          alle                   alle Geräte
#          raum:Wohnzimmer+typ:licht   beides muss passen
#  Bei raum:/typ:/alle werden nur Geräte geschaltet, die den Schlüssel
#  kennen (ein Rollladen hat kein "power").
#
#  Am einfachsten legst du Szenen im Dashboard unter Automation an.
#
#  Symbole: mond, sonne, aus, film, haus, weg, kaffee, stern, schnee, feuer
